# source-command-status

Use this skill when the user asks to run the migrated source command `status`.

## Command Template

Read PLAN.md and PROGRESS.md. Report: current phase and its status, phases remaining, any audited-fail items outstanding, and the last 3 decision-log entries. Keep it under 15 lines.
